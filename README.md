Repo ini pada dasarnya adalah tempatku nyimpen tugas mata kuliah **Pengembangan Aplikasi Web** di UIN Sunan Gunung Djati Bandung, sekaligus jadi *playground* buat ngulik hal-hal mengenai *web*.

## Tech Stack & Fitur

**1. Halaman Beranda:**

* Astro
* Tailwind CSS v4
* Transisi Halaman Mulus (ClientRouter)

**2. Halaman Tugas 01 - Profil Diri (`/profil`):**

* 100% HTML5 Semantik
* Tabel jadwal kuliah & Biodata singkat
* Meta tag & OpenGraph
* Dark / Light Mode
* Dukungan penuh Aksesibilitas (a11y)

## Struktur Utama

* `src/pages/index.astro` ➔ Halaman Beranda.
* `src/pages/profil/index.astro` ➔ Halaman pengerjaan Tugas 1.
* `src/styles/global.css` ➔ Konfigurasi gaya dan Tailwind v4.
